# Predicting Human Annotator Disagreement: The Project Overview

This is a machine learning project pretending to solve human annotator
disagreement. It takes CIFAR-10H soft labels—where humans couldn't agree on what
a blurry 32x32 pixel block is—and trains a ResNet-18 to emit the same uncertain
garbage. The pipeline pushes images through a standard backbone, slaps on a
linear or MLP head, and minimizes divergences (KL, JS, Earth Mover's) between
the model's confusion and human confusion.

It builds models, evaluates them, runs ablations, and leaves an embarrassing
graveyard of empty test files. It mostly works, but you clearly got lazy halfway
through building the directory structure.

---

## Subsystems (Directories)

**`analysis/`** Contains scripts to calculate entropy on distributions and spit
out a few static plots.

**`data/`** Ingests CIFAR-10H data, ruins it with random crops, and spits out
stratified validation splits. It is the only sane and fully implemented part of
the codebase.

**`evaluation/`** Computes divergence metrics and draws plots to justify your
existence. It loads checkpoints, generates `[N, 10]` predictions, and correlates
model entropy with human entropy.

**`experiments/`** A glorified bash script wrapper masquerading as an experiment
manager. Stores YAML configs to run different loss ablations.

**`explainability/`** Contains Grad-CAM scripts. It is completely empty because
nobody actually understands what these networks learn anyway.

**`losses/`** Mathematical punishment for bad predictions. It contains KL, JS,
custom composites, and Sinkhorn distance functions to force the model to mirror
human confusion.

**`models/`** The PyTorch plumbing. A hacked-up ResNet-18 that dumps `[B, 512]`
features into linear or MLP heads to yield `[B, 10]` probabilities.

**`notebooks/`** Jupyter notebooks for data exploration. Standard scratchpad
garbage you forgot to delete.

**`outputs/`** Where your models, CSV metrics, and matplotlib figures go to die.

**`tests/`** A barren wasteland of empty Python files. You wrote zero tests.
Predictable.

**`training/`** The standard PyTorch boilerplate loop. It shoves batches through
models, scales gradients for mixed precision, and saves best checkpoints.

**`utils/`** Device selection boilerplate because nobody can remember how to
check for Apple Silicon (`mps`) natively.

**`visualisations/`** A collection of empty files. You planned to write modular
plotting code, but clearly got tired and stuffed it into `evaluation/` instead.

### `losses/`

**`losses/kl_divergence.py`**

- **Summary**: PyTorch's `F.kl_div` wrapper for soft targets.
- **Details**:
  - `kl_divergence(pred_probs: Tensor[B, 10], target_probs: Tensor[B, 10])` ->
    `Tensor[]` (scalar loss).

**`losses/js_divergence.py`**

- **Summary**: Jensen-Shannon divergence loss.
- **Details**: Symmetric version of KL divergence. Averages per-sample KL to a
  mean distribution `M`.
  - `js_divergence(pred_probs: Tensor[B, 10], target_probs: Tensor[B, 10])` ->
    `Tensor[]` (scalar loss).

**`losses/custom_losses.py`**

- **Summary**: Composite loss function penalizing both distribution and entropy
  divergence.
- **Details**: Blends KL divergence and absolute entropy error using a `beta`
  factor.
  - `custom_composite_loss(pred_probs: Tensor[B, 10], target_probs: Tensor[B, 10], beta: float)`
    -> `Tensor[]` (scalar loss).

**`losses/emd_loss.py`**

- **Summary**: Differentiable Earth Mover's Distance using Sinkhorn iterations.
- **Details**: Solves optimal transport using a pre-defined 10x10 semantic cost
  matrix. Loops matrix multiplications `max_iter` times. It runs slowly, but it
  works.
  - `sinkhorn_loss(pred_probs: Tensor[B, 10], target_probs: Tensor[B, 10], cost_matrix: Tensor[10, 10], epsilon: float, max_iter: int)`
    -> `Tensor[]` (scalar loss).

**`losses/utils.py`**

- **Summary**: Another empty utils file.
- **Details**: See my previous rants about making files for no reason.

**`losses/__init__.py`**

- **Summary**: Loss function factory.
- **Details**: Uses
  `get_loss_function(loss_name: str, beta: float, epsilon: float)` -> `Callable`
  to bind parameters and return the requested loss.
